The memory hierarchy, and why tiles are the whole game

A GPU is a pyramid of memories. At the bottom, HBM — 80 GB, but only 3.2 TB/s away. At the top, the registers next to each core — 100+ TB/s, but 256 KB per SM. Every kernel's speed is decided by one question: how many times does each byte cross the slow edge of the pyramid? This animation runs a tiled matrix multiply C = A · B across three streaming multiprocessors and lets you watch tiles climb the hierarchy — then flip to the naive kernel and watch the same math drown in HBM traffic.
